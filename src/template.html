SYSTEM NOTE / 漫游说明

这是第一人称无重力漫游。你的身体不受建筑碰撞限制，因此可以贴近任何一座建筑观察它的立面、屋顶机械与层间管线，也可以直接下潜到地面以下。

SPACE / C 是垂直推进器，按住 SHIFT 可以快速抵达目标层。滚轮改变基础航速；如果迷路，按 T 打开垂直交通目录，或按 1 / 2 / 3 直接前往三个主层级。

城市不是一张背景图。所有的塔、厂房、管道、立交、贫民窟单元都在运行时独立生成，并通过竖井、货运轨道、电梯、管线与空中桥梁互相连接。

提示：把视线压低 20°，你会看到中央竖井。按 SPACE 上升，经过立交后再按 C，可以体验从 800 米俯冲到 -1000 米的完整垂直剖面。
